# Campus Connect College Club

A responsive four-page college club website built using HTML5
and CSS3.

## Project Overview

Campus Connect is a college club website designed to connect
students, encourage participation in activities, and provide
information about club events and registration.

## Pages

1. **Home Page (index.html)**
   - Introduction to Campus Connect.
   - Welcome message.
   - Club benefits.
   - Join Now button.

2. **About Page (about.html)**
   - Club introduction.
   - Mission and vision.
   - Upcoming events table.

3. **Registration Page (registration.html)**
   - Student registration form.
   - Personal information fields.
   - Radio buttons and checkboxes.
   - Department selection.
   - File upload option.

4. **Contact Page (contact.html)**
   - Contact information.
   - Email and phone details.
   - Message form.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

## Features

- Four connected web pages.
- Responsive navigation bar.
- Common CSS stylesheet.
- Registration and contact forms.
- HTML form validation.
- Responsive mobile-friendly layout.
- Custom SVG favicon.

## Project Structure

```text
college-club-site/
│
├── index.html
├── about.html
├── registration.html
├── contact.html
├── styles.css
├── favicon.svg
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Navigate through all four pages.

## Important Note

This is a static front-end project.
Forms use action="#" and do not store or send
submitted information to a server.
